# FinScope

Open-source financial and economic intelligence dashboard built with Python.

FinScope is a beginner-friendly project for exploring core personal-finance calculations and public economic indicators. It includes simple and compound interest, investment return, inflation-adjusted value, World Bank indicator charts, and CSV export.

## Run locally

```bash
python -m venv .venv
# Windows: .venv\\Scripts\\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

## Tests

```bash
pytest
```
